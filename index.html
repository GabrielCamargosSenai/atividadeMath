Math.random

Conceito:

A função Math.random(), retorna um número aleatório, em um intervalo de [0, 1]. Porém, o valor nunca chegará a ser 1, o valor pode chegar a 0.999999... , mas nunca irá chegar a 1. O intervalo pode ser alterado para sortear um número, como exemplo, valores de 1 a 6.

Exemplos:

Intervalo Padrão:

Math.random(); //Return: 0.27
Math.random(); //Return: 0.999

Intervalo Definido:

const dado = Math.floor(Math.random() * 6) + 1; //Return: 5

A aleatolarização do número será da seguinte maneira: o Math.random();, entregará um número no intervalo de 0 a 1, o valor será multiplicado por 6 e acrescentado mais, pois, sem o + 1, o valor iria até 5, não até 6 com esperado. Ex: 0.75 x 6 = 4.5, o Math.floor, tira a vírgula, deixando 4, somando com 1, resulta em 5

Math.floor

Conceito:

A função Math.floor();, transforma um número decimal em inteiro, arredondando-o para baixo

Exemplos:

Positivos:

Math.floor(4.2); // 4
Math.floor(4.9); // 4 (mesmo perto de 5, desce)
Math.floor(7); // 7 (já é inteiro, não muda)
Math.floor(0.75); // 0

Negativos:

Math.floor(-4.2); // -5
Math.floor(-2.2); // -3
Math.floor(-7.2); // -8
Math.floor(-0.2); // -1
